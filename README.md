# The Long View

A calm five minutes with a big idea, every evening: the thinkers who help us understand how people live together, to read or to listen to.

**Read and listen: https://theknowledgecabinet.github.io/long-view/**

Podcast feed: https://theknowledgecabinet.github.io/long-view/feed.xml

## How it is made

The content is written by a [Hermes](https://github.com/NousResearch/hermes-agent) AI agent.
Every evening it takes one reading from a long list anchored on the essayist Lee Harris
and the thinkers around him (Ibn Khaldun, Tocqueville, Hoffer, Arendt and many more),
fetches and reads the source, and writes a short, appreciative lesson: the idea in
brief, the bigger picture, another angle, and a question to take into the evening.
A local AI model then checks the summary against the source text before it is published.
Each edition links to its original reading, which is always worth your time.

- **Audio:** each edition is read aloud by a text-to-speech model (Kokoro, a British
  voice), so the site doubles as a podcast.
- **Images:** freely licensed images from Wikimedia Commons; each page credits the
  artist and licence.
- **This repo:** rebuilt automatically after each new edition and served by GitHub Pages
  (Jekyll, branch `main`). Every file is generated, so edits made here are overwritten.
